OUTPOST: LAST WATCH — QUICK INTEGRATION GUIDE

1) Copy asset folders into your game:
   - backgrounds/*  -> assets/art/backgrounds/
   - characters/*   -> assets/art/characters/
   - ui/*           -> assets/art/ui/
   - icons/*        -> assets/art/icons/
   - branding/*     -> assets/art/branding/

2) Update src/assets.js file paths to PNGs:

const files = {
  raiders: 'assets/art/characters/raider_atlas.png',
  warden: 'assets/art/characters/warden_atlas.png',
  portrait: 'assets/art/characters/warden_character_sheet.png',
  title: 'assets/art/backgrounds/title_backdrop_main.png',
  mapFrontier: 'assets/art/backgrounds/map_homestead_storm.png',
  mapOrchard: 'assets/art/backgrounds/map_ashen_fortress.png',
  mapFrost: 'assets/art/backgrounds/map_frozen_fortress.png'
};

3) Update map card images in src/maps.js:
Replace:
  assets/art/maps/map-${map.id}-960.webp
With one of these explicit mappings:
  frontier -> assets/art/backgrounds/map_homestead_storm.png
  orchard  -> assets/art/backgrounds/map_ashen_fortress.png
  frost    -> assets/art/backgrounds/map_frozen_fortress.png

A quick implementation:

function previewForMap(id) {
  switch (id) {
    case 'orchard': return 'assets/art/backgrounds/map_ashen_fortress.png';
    case 'frost': return 'assets/art/backgrounds/map_frozen_fortress.png';
    default: return 'assets/art/backgrounds/map_homestead_storm.png';
  }
}

Then inside renderPicker() use:
  <img src="${previewForMap(map.id)}" alt="" />

4) Armory / consumable icons
arsenal.js already expects icons under:
  assets/art/icons/${id}.webp
and light versions:
  assets/art/icons/${id}-192.webp

If you stay with PNG files, either:
A. Convert the PNG icon sheet into individual icon files and export as WEBP, or
B. Change iconImg() in arsenal.js from .webp to .png and point to the new filenames.

5) Branding
Use branding/game_emblem.png on the title screen, loading screen, or event poster.
